# HS2 AnimKit

把 **Honey Select 2** 的角色、动作和 H 道具直接搬进 Blender，改完再导出成 FBX。

你不需要先研究骨架、控制器或游戏文件结构。装好插件后，基本就是：

> **选一条动作 → 看 → 想改就拖控制器 → 导出。**

---

## 能做什么

- 载入 HS2 男女素模和游戏原骨架
- 浏览、搜索并播放游戏里的 Studio 动作
- 播放 H 动作，自动安排人数、性别和道具
- 在 H 动作的阶段之间切换（待机、抽插、绝顶等）
- 用 FK / IK 控制器改姿势，或者直接改动作
- 左右镜像、慢放、放回地面、生成根运动
- 导入 MMD 的 VMD 和 Mixamo FBX
- 导出带骨骼动画的 FBX，给 UE / Unity / 其他引擎使用

---

## 安装

### 需要什么

- Blender **4.0 或更新版本**
- 一份已经安装好的 Honey Select 2 本体
- 插件会读取游戏里的 `abdata` 数据，但**不附带任何游戏素材**

### 用 zip 安装（推荐）

1. 下载发布页里的 `HS2RigKit_addon.zip`
2. 打开 Blender：`编辑 → 偏好设置 → 插件`
3. 点右上角 `从磁盘安装`，选择这个 zip
4. 在插件列表里搜索 `HS2 Anim Kit`，勾选启用
5. 按 `N` 打开 3D 视图侧栏，找到 `HS2` 标签页

## 第一次使用

1. 打开侧栏的 `HS2 → 动作`
2. 第一次会要求选择 **HS2 游戏目录**
   - 选 `abdata` 的**上一级**目录，不是 `abdata` 本身
   - 例如 `D:\game\HS2`
3. 插件会自动建立动作索引
   - 第一次大约 30 秒
   - 之后会读缓存，基本秒开
4. 索引完成后，直接点列表里的动作就能播放

## 五分钟上手

### 1. 播一条 Studio 动作

打开 `HS2 → 动作`，上方选 `工作室动作`：

- 在搜索框里输入动作名的一部分
- 用右边的分类 / 小类下拉缩小范围
- **点一行就开始播**
- 需要的人（和道具）会自动进场

底部显示当前列表数量和刷新按钮。只有游戏里新增了动作包时，才需要手动点刷新。

### 2. 播一段 H 动作

切到 `H 动作`：

- 上方可以筛选人数：全部 / 单人 / 男女 / 百合 / 3P
- 可以搜索日文名
- 右边的道具开关决定要不要一起加载道具
- **点一行 = 自动放好所有演员和道具，并开始播放**

选中一段 H 动作后，下方会出现它的阶段列表：

- 待机
- 抽插、弱 / 中 / 强
- 绝顶
- 等等

**点阶段只会切动作阶段，不会重新换人。** 多人动作会一起切换。

### 3. 改姿势

打开 `HS2 → 调整`。

如果场景里有多个演员，顶部会出现 `编辑对象` 按钮。先点一下你要改的人，下面的工具只对他生效。

第一次改动作前，先加控制器：

- 点 `给所有演员加控制器（FK + 手脚 IK）`
- 需要手指控制器时，勾选 `连手指一起做`
- 一般不用勾，手部姿势可以用现成的手势

加完以后：

- 直接拖场景里的控制器改姿势
- 每个手脚控制器都有 `ik` 滑块：`0` 是 FK，`1` 是 IK
- `关节校正` 控制膝盖、手肘等位置的补偿骨
  - 播游戏动作时默认关闭，保持和游戏一致
  - 自己改关节，或导入 VMD 时，再打开

改完姿势后，可以：

- `重打控制器帧`：把控制器当前的位置写进整段动作
- `控制器吸附姿势`：让控制器跟上当前骨骼
- `IK 写回 FK`：把 IK 结果写回 FK 骨骼

### 4. 手势

在 `调整` 里展开 `手势`：

1. 左右手各选一个手势（共 21 种）
2. 选择是否在当前帧写关键帧
3. 点 `写入关键帧`
4. 点 `还原` 可以恢复原来的手部姿势

选手势时就会预览，不会立刻改动画。

### 5. 身高和体型

如果当前动作有 S / M / L 身高档，`调整` 顶部的 `编辑对象` 下方会出现：

- `身高档位`
- 或 `胸围档位`

选哪一档，就播放哪一档的动作。身高档位还会同步缩放身高骨骼，让手和胯的位置对得上。

没有变体的动作不会显示这个选项。

### 6. 动作后处理

`调整` 里的 `动作后处理` 会生成一条新动作，原动作保留：

- `左右镜像`：左右互换
- `放回地面`：把角色整体挪回地面，不改变姿势
- `慢放一倍`：帧数翻倍，做慢镜头或补细节

需要把 Hips 的运动抽到根骨时，用 `根动画`：

- `水平位移`
- `转向`
- `垂直位移`

勾选需要的项目，再点 `生成根动画动作`。

### 7. 导出 FBX

1. 在场景或大纲里选中角色骨架
2. `文件 → 导出 → FBX`
3. 勾选 **仅变形骨 / Only Deform Bones**
4. 导出

控制器骨不会带出去，导出的就是游戏原来的变形骨架和动画。

默认不导出网格；需要模型一起带走时，在 FBX 导出设置里打开网格导出。

## 外部动作

`动作 → 外部动作` 是另一种用法：动作不是来自 HS2，而是你手上的 VMD 或 Mixamo FBX。

### VMD

点 `导入 VMD（MMD 舞蹈）`，选择 `.vmd` 文件。

- 默认使用虚拟 MMD 骨架，保留 MMD 的 IK、扭转骨和角色配置
- 可以在导入选项里选 `chara_*.ini` 角色配置
- 没有演员时会自动放一个
- VMD 不做贴地，脚在哪儿就是哪儿

### Mixamo FBX

点 `导入 Mixamo FBX`，选择带皮肤的 FBX。

- 按 `mixamorig:*` 骨骼名自动映射
- 体型差会按身高比例缩放
- 导入时可以顺便做足部贴地和关节校正

### 手动放人

展开 `手动放人（自制动作用）`：

- `+ 女角`
- `+ 男角`
- 点角色名切换当前编辑对象
- 点后面的 `X` 删除角色

## 面板速查

### 动作

- `工作室动作`：搜索、分类、点一行播放
- `H 动作`：按人数筛选、搜索、带不带道具、选阶段
- `外部动作`：VMD / Mixamo / 手动放人

### 调整

- `编辑对象`：多人场景里切换当前演员
- `身高 / 胸围档位`：动作有变体时才显示
- `控制器`：IK 开关、关节校正、打帧、吸附、写回
- `动作后处理`：镜像、贴地、慢放
- `根动画`：把位移和转向抽到根骨
- `手势`：21 种手部姿势

## 常见问题

### 打开后没有动作

- 确认游戏目录选的是 `abdata` 的上一级
- 关掉面板再打开，或点列表底部的刷新按钮
- 第一次建索引需要等一会儿

### 点动作没反应

- 先看面板底部有没有报错
- 游戏目录不正确，或者这个动作包读不出来
- 可以点刷新重新扫描

### H 动作里男角是 T-pose

有些 H 模式在游戏数据里本来就没有男角动作。插件会把男角放进去，但没有动作可播。

### 道具是纯色的

道具贴图未解包，当前用材质主色显示。

### 衣服、头发、胸部没有物理

插件只处理骨骼动画。裙摆、头发、乳摇等物理骨不会自动模拟，导出后是刚性的。

### 插件列表里有好几个 HS2 Anim Kit

这是旧版部署方式留下的备份目录。运行：

```powershell
python tools\deploy.py --clean
```

清理后再用 `--status` 确认状态。

## 已知限制

- 表情和 VMD morph 还没做，面部骨会完整带入，但不会自动对口型或表情
- 裙摆、头发、乳摇等物理效果不包含在动作里
- 道具贴图暂未解包
- 部分 H 模式缺少男角动作，这是游戏数据本身如此
- Studio 控制器是近似实现，不是完整的 FBBIK
- VMD 不会自动贴地
- 关节校正在极端姿势下仍可能有误差
